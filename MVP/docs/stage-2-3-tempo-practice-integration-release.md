## Темп

Tempo Navigator переиспользует геометрию и указательные жесты Round Navigator. Верхняя и нижняя кнопки изменяют базовое значение на 1 BPM. Ползунок поддерживает перетаскивание, центральная кнопка открывает числовой ввод 20–300 BPM и возврат к авторскому темпу. Старое поле BPM скрыто. Метроном остался отдельным переключателем.

`TempoOffset = UserBPM − OriginalInitialBPM`. Для каждого участка `EffectiveBPM = max(20, OriginalCurrentBPM + TempoOffset)`. При исходном темпе 90 и установленном 60 BPM карта 90 → 150 → 110 → 70 → 40 → 90 даёт 60 → 120 → 80 → 40 → 20 → 60. При выходе из участка с ограничением действует исходное смещение −30 BPM. При базовом BPM 300 фактический темп на участке исходного BPM 150 достигает 360. Ввод вне диапазона оставляет установленный BPM прежним. Исходная карта не меняется.

Контроллер интегрирует реальное время по участкам карты, сохраняя позицию при смене BPM. Будущие события планируются по новой карте. Запланированный Note Off уже звучащего голоса пересчитывается без повторного Note On. Pre-count сохраняет пройденную музыкальную долю. Выбор сохраняется под прежним ключом `play12.tempo.v1` с дополнительным признаком возврата к авторскому темпу. Резервные копии прежнего формата читаются штатно.

## Интерфейс и Tutorial

Practice, Left Hand, Right Hand и неактивный One Skill размещены над штатными элементами Loop, From, To, Reset range и Pre-count. Лента микрораундов продолжает использовать прежний контроллер. Ширина правого коридора определяется существующей компоновкой. В узкой раскладке панель открывается через вкладку «Раунды». My Melodies сохраняет ширину и размеры строк, нижняя граница совпадает с нижней границей нотного поля, список прокручивается внутри доски.

Spotlight подстраивает отверстие маски под Tempo Navigator, объединённую панель Practice и группу Loop. Существующие подцели выбора рук, Loop, диапазона и Pre-count остались в прежних шагах. Тексты, условия прохождения, переходы и формат прогресса сохранены. Фраза «Измените скорость кнопками рядом с BPM» не описывает новое вертикальное расположение стрелок буквально. В Tutorial вместо My Melodies отображается отдельная панель прогресса обучения.
