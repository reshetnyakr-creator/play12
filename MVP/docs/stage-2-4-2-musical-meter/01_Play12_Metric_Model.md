# Метрическая модель

Авторский учебник, главы 3, 4 и 9–12, определяет пульс как равномерный. Раунд группирует основные счёты. Счёт может делиться на «И» и «А» без ускорения пульса. Высота нотного блока пропорциональна длительности. Акценты 36/24/12% совпадают с имеющимися значениями Renderer.

`score.editor.metricMap` версии 1 хранит раунды и темповые отметки. Раунд содержит исходный размер, фактические границы, номинальную длину, фазу затакта и основные счёты. Каждый счёт содержит начало и длину, индекс в полном такте, наличие пульса, акцент и шаги. Координаты хранятся как сокращённые рациональные четверти. Для фермат выводится параллельное представление в исполнительской координате текущей архитектуры. Note ID и длительности нот по-прежнему формируются в импорте.

12/8, 9/8 и 6/8 по традиционной модели группируют восьмые по три. Запись 2+3/8 задаёт пять равных ударов с вторичным акцентом на третьем, а 3+2/8 — на четвёртом. Это рабочая интерпретация явной записи для Play12. Размер с неустановленной группировкой получает базовый равномерный счёт, сохраняя диагностику. При свободном метре сохраняются события и границы без искусственного счёта. Локальные бинарные и тернарные позиции выявляются по письменным границам событий, без квантования нот.
