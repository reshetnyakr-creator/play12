# Play12 Stage 2.4.2

Play12 различает музыкальное время, основной счёт и его подразделения. Для Perfect измерены 69 тактов 12/8, четыре основных счёта на такт, 63 BPM на панели, 94,5 QPM во внутреннем расписании и 4:22,857 рассчитанной длительности. При −10 BPM внутренний темп составляет 79,5 QPM. Renderer и метроном получают позиции из одной метрической карты.
