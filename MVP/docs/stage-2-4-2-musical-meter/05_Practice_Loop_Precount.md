# Practice, Loop и Pre-count

Practice использует локальный период основной доли для повторного окна ответа. Реальная атака ожидаемой ноты остаётся на точной координате события. Тренировка руки фильтрует ноты, сохраняя метр и границы раунда. Loop сохраняет выбор диапазона и завершает очередь на правой границе цикла.

Pre-count использует длительность номинального раунда и основную единицу пульса. На сильной позиции сохраняются два цикла. Для затакта учитывается исходная фаза. Трассы синтетического 12/8 и Perfect показывают восемь щелчков на два цикла, четыре на первый звучащий раунд и повторный отсчёт при Loop.
