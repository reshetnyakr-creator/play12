# Реестр решений

| Решение | Статус и источник |
| --- | --- |
| Пульс равномерен, раунд группирует счёты, шаги И и А подчинены счёту | Авторский учебник, главы 9–12 |
| Градация акцентов 36/24/12 | ТЗ и действующий профиль Renderer |
| Устойчивые согласованные рёбра | Дополнительные признаки с уверенностью INFERRED. Одного такта недостаточно. |
| Показ Tempo Navigator | При постоянной единице BPM соответствует пульсу. При переменной единице показывается QPM и сохраняется прежняя абсолютная поправка. Новое правило смены единицы согласуется отдельно. |
| Свободный метр | Ритм и время импортируются. Учебные счёт, пульс и Pre-count отсутствуют. |
| Размер без явной группировки | Ровная базовая разметка с отметкой неопределённости. Внутренние акценты получают только размеры с подтверждённой моделью. |
| Совместимость | Применять карту только при совпадении музыкальных координат. Пересчёт сохранённого времени требует отдельного решения. |
| Звук вторичного акцента, сложные слоги, относительные метрономические указания, внутритактовые изменения размера | Открыто. Сохраняются исходные данные. |
