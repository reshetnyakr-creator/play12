# Play12 Stage 2.3.4 — Tutorial Layout & UI Consistency

База и точка отката [rollback-before-stage-2-3-4](https://github.com/reshetnyakr-creator/play12/tree/rollback-before-stage-2-3-4) указывают на `29760f4118215cc24d20e7b5bb2d1341770cae67`.

## Исправления

- **Practice Board.** Раньше атрибут `hidden` убирал весь Round Board из раскладки, и Practice Board росла на этапе 5. Общая доска Main и Tutorial теперь целиком видна с этапа 3. До разблокировки нижняя часть сохраняет размеры и отключена через `inert`. На время блокировки также отключены выполнение Loop, Pre-count и резервные команды навигации через доску.
- **Финальная подсказка.** При пересечении целей Spotlight её ранее вставляли в поток центральной зоны, где она занимала место нотного поля. Теперь подсказка закреплена поверх интерфейса и центрирована на Desktop. В альбомной ориентации телефона сохраняется боковое размещение, где оно помещается. Spotlight использует фактические прямоугольники нотного поля и клавиатуры.
- **Список этапов.** Скрипт ограничивал список высотой трёх этапов, мобильный CSS дополнительно ограничивал его 240 px. Список теперь использует доступную внутреннюю высоту, а CSS включает прокрутку по переполнению. MutationObserver и ResizeObserver подводят активный этап к ближайшему видимому краю только при необходимости.
- **Скругления.** Общая доска имеет внешний радиус 24 px и внутренний радиус кнопок Practice 16 px при отступе 7×6 px и зазорах 2 px в ряду. Активное, обычное и отключённое состояния используют одинаковую форму.
