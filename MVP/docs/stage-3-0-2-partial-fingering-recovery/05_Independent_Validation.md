# Независимая валидация

verify.py сверяет планы, прежние пальцы, принадлежность к руке и распространение пальца на все ID лиги. Отдельная проверка по пересечениям интервалов проверяет совпадение клавиш между руками, занятость пальца, октавы и MaxPrac. Существующие пересечения двух базовых назначений оставлены в исходной карте.

На действующем плане фиксированных пальцев проверочный DP независимо исчерпал доступные варианты. Time максимум +44 при учёте занятости клавиши между руками. Первый кандидат +48 включал пары P1.m40.e0/P1.m40.e6, P1.m40.e0/P1.m40.e9, P1.m44.e0/P1.m44.e6 и P1.m44.e0/P1.m44.e9. Stage 3.0.1 перебирал руки по отдельности, поэтому эти пересечения не ограничивали максимум. Это ограничение оценки, а не обнаружение новой ошибки MusicXML или изменения контактов. У текущей карты новых конфликтов ноль.
