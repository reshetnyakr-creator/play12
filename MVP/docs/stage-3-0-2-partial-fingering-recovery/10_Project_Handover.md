# Handover

Сохранены основной код, тесты, регрессионные измерения и четыре реестра. Рабочая ветка feature/stage-3-0-2-partial-fingering-recovery основана на 0ef67717befb1735363bfe8fa48812f3ce9cb9d3. Состояние — кандидат, порог Time не достигнут по доказанному конфликту критериев. Для решения об изменении порога использовать [независимый расчёт](05_Independent_Validation.md) и [протокол](09_Release_Protocol.md).

Из корня репозитория запустить node --test MVP/tests/*.cjs и python -m unittest discover -s MVP/tests -p 'test_*.py'. browser-import.cjs принимает адрес локального сервера, приватную папку для выгрузок, число повторов и файлы. Задать CHROMIUM, PLAYWRIGHT_MODULE и при необходимости PLAY12_LOCALE=ru. verify.py принимает папки базового прогона, строгого кандидата, первого кандидата и папку публичного вывода. Полные документы не публиковать. Физическое MIDI и исполнительское удобство не проверялись.
