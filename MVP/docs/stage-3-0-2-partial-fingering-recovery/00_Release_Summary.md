# Stage 3.0.2 — результат рабочей ветки

Реализовано частичное восстановление после основного расчёта. Итоговые карты добавляют 44 ноты Time и 86 No Surprises, всего 130 нот в 113 физических контактах, без замены прежних пальцев. Time — 513/541, No Surprises — 1067/1101. Производственный релиз заблокирован обязательным порогом Time 517/541.

Первый вариант достиг обоих порогов. Независимая проверка отклонила четыре назначения Time: два перекрытия одной клавиши в такте 41 и два в такте 45 между руками. Во всех четырёх случаях другой контакт уже назначен и ещё удерживается. Проверяемый максимум без этих новых пересечений — 513/541. Подробности в [протоколе](09_Release_Protocol.md).
