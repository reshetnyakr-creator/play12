# Реализация и границы

Новый проход вызывается штатным MusicXML Import через флаг Worker. Полное покрытие возвращается сразу. Контакты и базовая карта переиспользуются. Связанные ID получают один палец. При повторном импорте результат восстановления не заменяет сохранённую книгу или ручные правки автоматически. Смена нуля в Main сохраняет прежний режим Worker. Версии URL ресурсов Import обновлены для загрузки нового кода.

Renderer, Converter, метрика, контактный план и beginner.json без изменений. Алгоритм для оставшихся нот не разрабатывался.
