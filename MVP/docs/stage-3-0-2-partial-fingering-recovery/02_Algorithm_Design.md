# Алгоритм

Сначала штатный Beam Search возвращает базовую карту. При неполном покрытии Worker рассматривает неназначенные контакты. Области образуются цепочками пересекающихся интервалов. Ранее назначенные контакты и их пальцы образуют фиксированные ограничения. Пропущенная атака может получить палец даже внутри прежней границы восстановления.

DP хранит пальцы ещё активных кандидатов. Для каждого контакта перебираются пустое назначение и пальцы 1–5. Одна клавиша не получает двух пересекающихся назначений. Пальцы одной руки не дублируются на пересечении. MaxPrac и октавы проверяются штатной функцией spanViolation. Приоритеты: покрытие исходных нот, число расширений, сумма превышений, стоимость формы и порядка пальцев плюс действующие штрафы большого пальца и мизинца на чёрных клавишах. Полная стоимость межслойных переходов основного движка пока не используется для ранжирования частичного решения.

Общий лимит времени следует неиспользованной части штатного бюджета. Лимит состояний берётся из текущего ограничения кандидатов. При отсечении остаются назначения завершённых областей, прошедшие проверку.
