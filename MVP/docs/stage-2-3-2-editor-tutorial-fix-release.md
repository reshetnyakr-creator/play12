# Play12 Stage 2.3.2 — редактор аппликатуры и восстановление Tutorial

Исходный релиз и точка отката `rollback-before-stage-2-3-2` — `e93cf67d5423aaa757d413fcb9c990d41483ae7d`. Итоговый SHA — коммит, содержащий этот протокол.

## Первопричина

На опубликованном RU Tutorial кнопка «Продолжить» открывала нотное поле с сообщением `Cannot read properties of null (reading 'addEventListener')` вместо партитуры. Полный стек перехваченного исключения получен в Chromium на локальной копии того же коммита. Входная страница, загрузчик, разметка плеера и оба задействованных скрипта сверены побайтно с production.

```text
TypeError: Cannot read properties of null (reading 'addEventListener')
    at Object.bindPractice (MVP/renderer/training-shell.js?v=stage23:9:517)
    at Object.connectRuntime (MVP/renderer/play12-onboarding.js?v=stage231:1220:57)
    at /ru/MVP/tutorial/:325:32
```

При объединении Practice Board и Loop Board кнопки оказались за пределами исходного DOM-контейнера Tutorial. Инициализация продолжала передавать этот контейнер в `bindPractice`. Функция не находила кнопки и завершалась исключением до подключения обработчиков обучения. Обработчик ошибки загрузки заменял SVG нотного поля строкой ошибки. Исправление передаёт непосредственно Practice Board, который остаётся владельцем кнопок даже после переноса панели. Учебные состояния, тексты, переходы и правила прохождения сохранены.

## Fingering Editor

Панель Undo, Redo, Save changes и Done центрируется по фактической ширине нотного поля. Переименование перенесено в строку My Melodies. Enter сохраняет название в существующей записи IndexedDB, Escape отменяет ввод. При конфликте ревизии сохранение останавливается. Изменение названия у активной мелодии сохраняет отдельный несохранённый черновик аппликатуры.

Исправленную панель проверили при 1440×900, 820×1180, 1180×820, 375×667 и 667×375 в RU/EN. На контрольной мелодии ширина панели — 283 px в EN и 342 px в RU, при ширине нотного поля 364,5–392,5 px. Края и центр проверены по `getBoundingClientRect()`. Через интерфейс проверены переименование, перезагрузка, экспорт и восстановление названия на чистом origin, назначение пальца, Undo, Redo, Save changes, Done и сохранность назначения после перезагрузки.

## Регрессия

- JavaScript 334/334, Python 9/9. Фикстура Tutorial теперь воспроизводит положение Practice Board вне исходного DOM-контейнера.
- Пройдены 10 конфигураций Main и 40 проверок Spotlight на пяти размерах в RU/EN. Проверены Tempo Navigator, стрелки, двойное касание, метроном, Practice, Loop и Pre-count.
- Проверены калибровка, переподключение и ошибки доступа через эмулированный Web MIDI. Физическая MIDI-клавиатура, iPhone и iPad не использовались.

## Полное последовательное прохождение

Два независимых прогона Chromium при 1440×900, RU и EN, завершились состоянием `ONBOARDING_COMPLETE`. Оба начались кнопкой Start и дошли до финального экрана через Play/Pause, выбор и подтверждение нуля, проверку карточек, Practice правой рукой, пять принятых нот с метрономом, выбор раунда 4, установку Loop 2–4, Pre-count, два успешных повтора и исполнение всей мелодии. Ввод проходил через клавиатуру браузера, мышь и касания экранного пианино. На шагах курса скрипт считывал ожидаемые ноты для выбора экранных клавиш. Переходы выполняло приложение по штатным условиям.

После начала курс показал нулевую позицию и загруженный SVG. В каждом прогоне страница перезагружалась после перехода к Practice, затем пользователь нажимал Continue и завершал курс с сохранённого этапа. В RU-прогоне во время первого этапа окно сужалось с 1440 до 690 px и расширялось обратно. Нотное поле и исходная позиция сохранились. Сообщение об ошибке загрузки после фикса не появилось. Симптом конечного времени на первом этапе отдельно не воспроизведён.
