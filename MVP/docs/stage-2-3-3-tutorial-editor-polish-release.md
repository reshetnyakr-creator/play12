## Изменения

1. Убрана дублирующая плашка названия в центре Tutorial. На Desktop 1440×900 нотное поле выросло с 386 до 450 CSS px, верхняя граница совпадает с левой информационной доской с точностью до округления. Ширина поля 392,5 px, координата Playback Board 546,16 px и координата пианино 611,16 px совпали с исходной версией. Название остаётся в информационной доске.
2. Проверка жёлтой и зелёной карточек подсвечивает ряд карточек и экранные клавиши одновременно.
3. Подсказка для Tempo Navigator содержит утверждённый текст RU/EN. Spotlight охватывает панель целиком и следует за ней при перетаскивании.
4. Русская подсказка тренировочного диапазона использует «От» и «До». Английская сохраняет From и To.
5. Финальная подсказка находится по центру рабочего пространства на Desktop, планшете в обеих ориентациях и телефоне в портретном режиме. В прежней версии при пересечении подсказки с областями Spotlight общий механизм размещения переносил её в боковую зону. Теперь финальная подсказка при таком пересечении занимает центральное место в потоке, сохраняя обе области Spotlight. В альбомном окне 667×375 используется существующая боковая зона с компактным оформлением текста, чтобы оставить доступ к полю и клавиатуре. Для этого окна также устранено чередование прокрутки между верхом и низом цели Spotlight, если цель выше её контейнера.
6. Основной карандаш Fingering Editor активирует точечное подчёркивание названия только выбранной мелодии. Нажатие на название открывает поле в той же строке. Enter и ✓ сохраняют, Escape и × отменяют ввод. Используются прежняя транзакция IndexedDB, проверка ревизии и обновление сохранённого черновика. Панель редактора содержит Undo, Redo, Save changes и Done.
