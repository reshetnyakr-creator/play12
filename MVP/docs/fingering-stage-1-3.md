# Fingering Engine Stage 1.3

База `b38a7a086847bcd0420acbd276c06f8f6ee1d924`. Точка отката `rollback-before-stage1-3-20261124`. Checkpoint поиска и регрессионных тестов `b10dcb6222458667828c905a1d4c1847d5e3c5be`.

## Причина и исправление

В такте 33 Interstellar нотоносец 2, голос 5, удерживает MIDI 41/48/53 с четверти 96 до 99 (события P1.m32.e5–7). Голос 6 атакует MIDI 53/60/65 с 97 до 99 (P1.m32.e8–10). Связующих лиг здесь нет. Получаются шесть записей контактов на пяти клавишах. Повторная атака F3 требует явного плана отпускания и передачи клавиши. Назначение второго пальца на удерживаемую F3 или автоматическое слияние голосов скрыло бы эту неопределённость.

На четверти 97 слой поиска оставался пустым: генератору требовались три свободных пальца при трёх удерживаемых контактах. Старый код прекращал весь поиск для левой руки. Теперь совпадающие атаки внутри одной руки без подтверждённого общего контакта помечаются как модельный конфликт. Поиск продолжает работу после границы отпускания. Сохраняются уцелевшие ветви поиска, занятые пальцы, предыдущая позиция и история переходов. Если атака внутри проблемного участка продлевает удержание, граница сдвигается. Исходные события, идентификаторы, длительности, голоса, связи лиг и принадлежность рукам сохраняются. Тесты отдельно проверяют восстановление при оставшемся зажатом пальце.

Для каждого неназначенного события результат Worker содержит внутренний код причины. Результат под временным лимитом может отличаться на разных устройствах. Лимит 12 с и внешний предел ожидания Worker 25 с сохранены. Число кандидатов на слой ограничено настройками профиля. Фиксированный общий бюджет кандидатов возможен как следующий шаг для воспроизводимости при отсечении, но потребует сравнения доли назначений на разных структурах материала.
