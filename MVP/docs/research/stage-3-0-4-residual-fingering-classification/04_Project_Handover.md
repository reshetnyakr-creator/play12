## Воспроизведение

Поднять локальный HTTP-сервер из корня checkout. Использовать browser-import.cjs из Stage 3.0.2, указав URL сервера, приватную папку выгрузок, число повторов 1 и два оригинальных файла MXL. Сырые результаты содержат партитуры и должны оставаться локально. Отдельно запустить:

~~~sh
D=MVP/docs/research/stage-3-0-4-residual-fingering-classification
PYTHONDONTWRITEBYTECODE=1 python "$D/classify.py" /tmp/private-imports /tmp/public-304
~~~

Для визуальной проверки открыть atlas.html через тот же локальный сервер. Chromium отрисовал семь фрагментов в четырёх группах штатным Renderer. Из каждого блока скачивается короткий диагностический MusicXML для обычной нотной записи. Фрагменты восстанавливают выбранные события и интервалы по исходным ID, но не заменяют исходную партитуру: оставлены только цель и пересекающиеся контакты. Оригинальные партитуры в результатах отсутствуют. Физическое исполнение не проверялось.

Следующее ТЗ должно отдельно согласовать физическую проверку G1/G2 и критерии слышимой сохранности голосов. Ни новое правило, ни экспериментальные отпускания здесь не применялись.
