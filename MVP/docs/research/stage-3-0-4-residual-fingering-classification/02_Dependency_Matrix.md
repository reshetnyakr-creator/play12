# Зависимости и защита от двойного учёта

| Пара | Проверенное пересечение | Риск при совместной работе |
| --- | --- | --- |
| G1–G2 | Один принцип исключительного владения и интервал освобождения; разные компоненты в измеренной карте | Нельзя считать общую прибавку от раннего снятия вкладом каждой группы |
| G1–G3 | Две компоненты Time, начинающиеся с P1.m42.e0 и P1.m46.e0 | Изменение владения меняет доступность баса и подвижных нот |
| G1–G4 | Две компоненты Time, начинающиеся с P1.m40.e0 и P1.m44.e0 | Выбор удержаний может переносить причину пропуска между группами |
| G2–G3 | Нет общей компоненты с первичными пропусками двух групп в карте | Общий эксперимент изменения интервалов требует повторной проверки связности и звучания |
| G2–G4 | Возможны одновременно повтор и частичное ограничение пальцев на том же интервале | Исправление повтора ещё не гарантирует свободный палец |
| G3–G4 | Частичные пальцевые ограничения встречаются как вторичные у группы G3 | Не считать освобождённый палец дополнительным результатом сверх решения общей компоненты |

У 17 нот G1–G3 дополнительно есть ограничения пальцев хотя бы от одного назначенного контакта в допустимом диапазоне. Это метка вторичного условия, а не утверждение, что G4 само по себе блокирует каждую такую ноту. Группы G1 и G2 не смешивают право владения и выбор пальца. В общей компоненте нужно предъявлять одну итоговую карту и повторно проверить интервалы обеих рук.

Потенциал включения по одной ноте: G1 — 0, G2 — 4, G3 — 16, G4 — 2 при том же максимуме. Число 22 относится к альтернативам по одной ноте, совместимость всех вариантов не доказана. Точное значение прироста в неизменной модели равно нулю. Матрица абляций Stage 3.0.3 отражает глобальные контрфактические карты, а не независимые выигрыши по группам.
