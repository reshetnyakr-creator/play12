# Уточнённые правила

| Правило | Прежнее | В эксперименте 3.0.9 |
| --- | --- | --- |
| R07 / R30 | Исключение у широкой пары и между членами широкого аккорда. | Исключение только для направленной 1–5. Для 4–5 нот обычные ограничения проверяются у каждой промежуточной пары. |
| R14 / R37 | Ориентация крайних пальцев и ранжирование по комфортности. | Для широких трезвучий допуск каждого внутреннего кандидата определяется MaxComf пары с мизинцем и MaxPrac пары с большим пальцем. Первым проверяется 2, затем 3 и 4. |
| R04 / R09 / R12 | Одновременные и удерживаемые контакты проверяются в физической карте. | Для недопустимой общей атаки допускается отдельная условная аппликатура со сменой позиции. Она не получает измеренного времени, педалирования или статуса физической выполнимости. |
| R37 | Направленная ориентация октавы применяется к обычной одновременной карте. | Сохраняется. Условная карта выводится в естественном порядке высот и помечается отдельно. |

Таблицы профиля и нумерация правил сохранены. Одновременное нажатие нескольких клавиш одним пальцем остаётся вне этапа.
