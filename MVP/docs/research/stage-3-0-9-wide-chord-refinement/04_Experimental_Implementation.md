# Экспериментальная реализация

Штатные режимы продолжают использовать прежние точки входа. Флаг `refinedChords` используется экспериментом Stage 3.0.9. Результаты 3.0.5–3.0.8 воспроизводятся исходными настройками. В режиме 3.0.9 область допустимых внутренних пальцев формируется по двум порогам, а проверка пар повторяется независимым проходом валидатора. Ни одна пара за пределами MaxPrac не принимается, кроме направленной 1–5.

Пересчитываются только аккорды, помеченные повторным аудитом. Связный участок используется из предыдущего плана. Поиск мелодического продолжения запускается локально после широкого трезвучия при неперекрывающихся атаках последующей группы. Для вариантов оцениваются прежние `positionShift` и `sameFingerMove`, затем число и величина сокращений и сохранность пальцев. Результат зависит от модели позиции и лимита поиска.

Общая атака допускает условную аппликатуру после двух проверок: совместный поиск с освобождением исчерпал совместимые варианты и сама тройка или группа 3–5 клавиш не имеет полного одновременного назначения. Проверка бюджета не используется как доказательство конфликта. Для условной карты выбираются разные пальцы в естественном порядке. Ручные и защищённые назначения сохраняются. Повторное использование одного пальца в одном аккорде отсутствует.

Условные пальцы добавляются только к отчётной аппликатуре. Физическая карта сохраняет собственную валидность, а условной записи не присваивается длительность удержания или время атаки. В JSON отдельно маркируются исключение крайней пары, освобождение контакта и последовательное исполнение. Для каждой категории сохранены источники нот и ограничения. Skill Bank и продуктовый интерфейс не менялись.
