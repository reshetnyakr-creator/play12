# Уточнение правил для экспериментального прохода

Аудит перед изменением опирается на [реестр предыдущего этапа](02_Rule_Audit.md) и действующий код проверки размаха, занятости и восстановления. Изменения охватывают только согласованное исключение MaxPrac и его диагностику.

| Правило | До согласования | В эксперименте |
| --- | --- | --- |
| R07 · предельное расстояние | Выход за парный MaxPrac исключает автоматическую пару. | Локальное исключение для направленной пары 1–5 одной руки при положительном перекрытии и интервале выше MaxPrac этой пары. Факт превышения сохраняется. |
| R14 · комфорт | Число пар сверх MaxComf и сумма превышений участвуют в сравнении допустимых путей. | Пороги и расчёт прежние. Широкий вариант участвует в существующем ранжировании и отдельно помечается. |
| R30 · все пары аккорда | Ограничения проверяются для всех одновременно занятых контактов. | Проверка каждой пары остаётся. Допуск одной пары не снимает ограничений третьей ноты или дополнительного отношения. |
| R37 · октавы и широкие интервалы | У октавы обязательна направленная пара крайних пальцев. Остальные интервалы ограничены профилем. | Октавная проверка прежняя. Для согласованного исключения широкой пары используется та же ориентация пальцев. |
| R04 / R05 / R09 / R11 / R12 / R55 · контакты | Занятые пальцы и клавиши, лиги, переатаки и физические интервалы проверяются раздельно. | Прежние условия. Исключение присваивает пальцы по уже принятому плану и не меняет физическую последовательность. |
| R39 / R45 / R47 / R58 · рука и пользовательская карта | Запрещены скрытые переносы, ручные значения защищены. | Прежние условия. Соседний автоматический палец может измениться только в локальном экспериментальном поиске. |

Новый номер правила не введён. Подтверждение физической выполнимости и способ исполнительской подачи широкого интервала находятся вне эксперимента.
