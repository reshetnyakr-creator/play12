# Экспериментальная реализация широких интервалов

Исключение включается только из [экспериментального запуска](wide-experiment.cjs). Обычный Worker, импорт, редактор и штатный проход поиска его не включают. Изменение экспериментального ядра находится только в исследовательской ветке. Предыдущие возможности Stage 3.0.5 пересчитываются до включения новой политики.

1. Поиск получает исходный контактный план Stage 3.0.5. Применяются точные полуоткрытые интервалы. Одинаковое и последовательное начало обрабатываются одинаково при положительном перекрытии. Совпадение физической клавиши, занятость пальца, правило октавы и все непредусмотренные превышения остаются блокирующими.
2. Если фактический интервал превышает границу пары 1–5 и конфигурация направлена по руке, этот конкретный парный MaxPrac допускается. Для правой это нижний 1, верхний 5. Для левой это нижний 5, верхний 1. Профиль и его значения прежние. В аккорде дополнительные пары оцениваются отдельно.
3. Восстановление использует существующий интервальный поиск и оценки MaxComf, стоимости формы аккорда, порядка и положения пальцев на чёрных клавишах. Разрешены локальные пересмотры только ранее назначенных автоматических контактов, образующих широкий интервал с пропущенным соседом. Предыдущее назначенное событие нельзя исключить. При равном покрытии минимизируются изменения прежних пальцев, затем применяются существующие эргономические оценки. Новых весов нет. Ручные назначения и восемь восстановленных событий Stage 3.0.5 закреплены.
4. Валидатор отдельно перечитывает итоговую карту. Каждое исключение сообщает `eventIds` всех сегментов, `ids` контактов, `hand`, `fingers`, `midi`, `distance`, `comfortLimit` и `practicalLimit`, `comfortExcess` и `practicalExcess`, интервал перекрытия, `wideIntervalException: true`, `physical: unknown`. Это диагностическая запись для дальнейшего использования. Она не является планом физического исполнения.

Изменения ограничены узким экспериментальным проходом. Выводы о пропусках относятся к данной модели и допустимому локальному пересмотру. Глобальный пересчёт всех ранее назначенных соседей не проводился. Партитуры, руки, голоса, педали, лиги, длительности и интервалы контактов Stage 3.0.5 сохраняются.
