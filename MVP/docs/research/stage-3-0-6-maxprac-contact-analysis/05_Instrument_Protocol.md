# Протокол физической проверки

Статус — подготовлен для автора и преподавателя. Физическая выполнимость и акустическая сохранность Stage 3.0.5 и гипотез Stage 3.0.6 пока не подтверждены.

## Подготовка

Использовать оригинальные MXL и [атлас](atlas.html). Записать модель инструмента, ширину октавы по центрам одинаковых белых клавиш, тип механики, поддержку MIDI и педалей, комфортный диапазон исполнителя без усилия, опыт, исходный и пробный темп. Желательно синхронно фиксировать MIDI Note On/Off, CC64/CC66 при наличии размеченной педали, аудио и видео кистей. У акустического пианино опираться также на наблюдение за клавишей и аудио. MIDI Note Off сам по себе не измеряет высоту возврата клавиши или прекращение звука.

## Наблюдение по группам

| Тип | Фрагмент | Что сравнить |
| --- | --- | --- |
| A | Time 36 и No Surprises 9 | По партитуре определить момент совместного начала. Сопоставить положение обеих клавиш и диапазон руки. Не требовать от начинающего склонять кисть или дотягиваться с усилием. При неудобной позе зафиксировать отказ от пробы. |
| B | No Surprises 10–11 и 53 | Определить, какая клавиша ещё нажата при новой атаке. Зафиксировать, где слышно ослабление предшествующего звука. Для явной передачи руки отдельно проверить свободный путь, клавиши второй руки и возможность вести оба голоса. Это проба гипотезы, а не карта для обучения. |
| C | Time 43 | Зафиксировать бас до каждой дальней атаки и оценить его слышимость на всём требуемом интервале. Сравнивать физическое время отпускания и акустический результат. Эталон звучания при необходимости построить пораздельной записью голосов с исходными длительностями, сохранив её статус контрольной записи. |
| D | No Surprises 29–30 | Отметить контакт перед началом цели и новые контакты после неё. Проверить обе границы, непрерывность лиги и соседние атаки. Освобождение на самой границе в вычислениях не предоставляет времени на перемещение. |

Для любого сравнения выполнять пробу сначала в комфортном медленном темпе, затем в исходном темпе только при устойчивом повторении без дискомфорта. При напряжении или неудобной позе остановить пробу. Не добавлять педаль к оригиналам. При контрольном сравнении акустики обозначать любое сознательное отклонение от партитуры как диагностическую пробу, не кандидат на автоматическое использование. При повторных атаках сохранить журнал Stage 3.0.5 отдельно, измерять достаточное возвращение клавиши для конкретного инструмента.

## Одна строка записи на попытку

| Фрагмент и ID | Инструмент и темп | Руки и пальцы | MIDI-атаки и отпускания | Свободное окно и качество возврата | Движение и субъективное удобство | Слышимость баса, акценты, связность | Повторы | Решение |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |

Для решения вести три независимых статуса. Модель допускает / отклоняет. Инструмент и исполнитель подтверждают / не подтверждают / неизвестно. Звучание сохранено / изменилось / неизвестно. Заключение преподавателя для начинающих фиксировать отдельно от результата опытного исполнителя.
