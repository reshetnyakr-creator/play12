# MusicXML 4.0

| Элемент | Значение и результат для модели |
|---|---|
| attributes, divisions | Изменения атрибутов применяются в музыкальном порядке. divisions — число единиц на четверть. duration / divisions даёт рациональные четверти. |
| time, beats, beat-type | Сохранять каждую пару и строки вроде 2+3. 2/4+3/8 даёт длину 7/2 четверти. Один numerically parsed numerator недостаточен. Может действовать на отдельный staff. |
| interchangeable | Альтернативное обозначение размера. Хранить отдельно вместе с отношением. |
| senza-misura | Свободный метр. Длительность извлекается из событий, карта счёта может отсутствовать. |
| direction, direction-type | Семантика и визуальная привязка направления, например метроном, слова, педаль. |
| metronome, beat-unit, beat-unit-dot, per-minute | Печатная единица и значение, включая диапазон. Длительность точки прибавляет половину, вторая точка ещё четверть базовой длительности. Учитывать beat-unit-tied. |
| metronome-note, metronome-relation | Структурные отношения, включая метрическую модуляцию и swing. Известное отношение и предыдущая скорость иногда позволяют вычислить новую скорость. Отмечать неполные данные. |
| sound tempo | Четверти в минуту для звучания. 0 требует определения пользователем. Для числового расчёта предпочтителен явно заданный playback tempo, конфликт с печатной отметкой хранится. |
| duration, type, dot | duration задаёт временную длину, type/dot — запись. Применение множителя нотации к duration повторно изменит ритм. |
| time-modification, tuplet | Соотношение actual/normal и визуальные границы группы. Триоль либо дуоль может лежать внутри обычного метра и не меняет группировку такта. |
| beam | Подсказка группировки конкретного голоса. Учитывать уровень ребра, синкопы, редакторские исключения и согласие между голосами/тактами. |
| backup, forward, chord | Сдвигают курсор или переиспользуют атаку предыдущей ноты. Длина такта требует максимума по голосам, включая значимый хвост forward. |
| offset | У direction определяет положение относительно текущего курсора, при sound=yes применяется к звучанию. Вложенный sound offset имеет приоритет над direction offset. |
| measure implicit | Явный признак, используемый, в частности, для затакта. Короткий такт возможен и без него. Само значение не кодирует метрическую фазу. |

Источники группировки по убыванию надёжности: проверенная автором/пользователем группировка, явная аддитивная запись, согласованный традиционный профиль размера и музыкальные признаки. Темповый символ может усилить предположение, но задаёт единицу BPM. Стабильные рёбра, акценты и повторяющиеся атаки — дополнительные свидетельства. Если источники расходятся, хранить признаки раздельно с уверенностью и предлагать предпросмотр нескольких вариантов. Для обычных 6/8, 9/8, 12/8 применять привычный профиль с возможностью поправки. Для 5/8, 7/8, 11/8 при отсутствии подтверждения показать равный базовый пульс с пометкой о неопределённой группировке. Задуманный автором счёт и агогика могут отсутствовать в файле.

Официальные определения, ссылки на конкретные элементы и разделы собраны в [10_References.md](10_References.md).
