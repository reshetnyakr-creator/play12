# Выбор архитектуры

| Критерий | A. Локальная правка сложного метра | B. Карта счёта поверх текущей шкалы | C. Новое ядро музыкального времени |
|---|---|---|---|
| Корректность | Закроет типичные 6/8, 9/8, 12/8 в одной точке UI | Единые границы, переменный и неравнодольный метр при наличии данных | Наибольший охват, включая расширенное многопартийное время |
| Педагогическая простота | Вид улучшится, разные подсистемы могут давать разный счёт | Общий счёт, опциональные подразделения | Та же цель, больше решений перед первым релизом |
| Реализация | 1–2 дня, остаются дублирующиеся планировщики | Поэтапная работа 9–15 дней | Несколько недель с повторной приёмкой временной модели |
| Обратная совместимость | Высокая, если это локальный рендер | Версионный sidecar, сохранение данных и откат по флагу | Миграция контрактов, выше риск |
| Renderer | Исправление подписи рискует изменить геометрию самостоятельно | Читает события Count, ноты пропорциональны прежней шкале | Повторная интеграция с новой шкалой |
| Playback | Понадобится независимое исправление метронома | Clock остаётся, клики и фаза унифицируются | Повторная реализация seek, pause, loop, playback |
| Fingering Engine | Без прямого влияния | Без смены правил при неизменных контактах и темпе | Изменения интерфейсов и проверок времени |
| Производительность | Минимальные расходы | Линейная генерация событий, поиск по диапазону и планирование окна | Зависит от дизайна и миграции |
| Масштабирование | Низкое для аддитивных размеров и смены фазы | Метр можно расширять без переписывания событий | Высокое, но дороже сопровождение |
| Риск регрессий | Низкий для вида, высокий риск сохранить разнобой | Средний, подконтрольный флагом и независимыми шагами | Высокий |

Рекомендация B. На Perfect часы уже интегрируют корректную длительность, поэтому полезное изменение — дать потребителям общий список долей и единое преобразование в звуковое время. Отдельно исправить потерю единицы темпа, когда она действительно влияет на воспроизведение. Пересматривать ядро после измерений многопартийного конфликта, если текущий контракт окажется недостаточен.
