# Stage 3.0.3 — оставшиеся 62 ноты

| Композиция | Воспроизведённая карта Stage 3.0.2 | Строгий максимум | Получили палец из 62 | Прежний палец снят | Палец заменён |
| --- | ---: | ---: | ---: | ---: | ---: |
| Time | 513/541 | **523/541** | 20 | 10 | 0 |
| No Surprises | 1067/1101 | **1067/1101** | 0 | 0 | 0 |

Максимумы учитывают обе руки и отсутствие перекрывающихся независимых назначений одной физической клавиши. Time уже содержит два межручных пересечения MIDI 60 в исходной карте. Поэтому сохранить все 513 прежних назначений одновременно невозможно при строгом правиле владения. Результат 523 — исследовательская частичная карта с чистым приростом 10. Она не является разрешением на замену пользовательской аппликатуры.

27 из 28 остаточных нот Time и 15 из 34 No Surprises по отдельности могут войти в одно из решений с максимальным покрытием. Их одновременное назначение из этого не следует. На фиксированной карте найдены 42 пропуска с прямым препятствием MaxPrac, 10 с межручным владением, 4 с повтором той же рукой и 6 без единственной локальной причины. 39 подписей описывают наблюдаемые конфигурации.
