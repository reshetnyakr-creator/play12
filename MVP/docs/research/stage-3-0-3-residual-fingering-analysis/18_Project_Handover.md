## Воспроизведение

Из корня checkout поднимите локальный HTTP-сервер на 8774. Запустите штатный browser-import.cjs из каталога документации Stage 3.0.2 с адресом сервера, отдельной временной папкой, числом повторов 1 и путями к двум MXL и четырём контрольным XML. Укажите CHROMIUM и PLAYWRIGHT_MODULE по локальной установке. Сырые выгрузки включают полные сведения о партитуре и предназначены для локальной проверки.

~~~sh
D=MVP/docs/research/stage-3-0-3-residual-fingering-analysis
mkdir -p /tmp/stage303-public-results
python "$D/research.py" /tmp/stage303-private-imports /tmp/stage303-public-results
PYTHONDONTWRITEBYTECODE=1 python "$D/test_research.py"
~~~

Откройте /MVP/docs/research/stage-3-0-3-residual-fingering-analysis/patterns.html через локальный HTTP-сервер, чтобы увидеть схемы всех 39 паттернов и скачать синтетические MusicXML. В Chromium проверена отрисовка всех 39 SVG. Файлы CSV содержат только диагностическую часть; pitches в схемах нормализованы, а время измерено в четвертях от локального начала.

Нерешённые части: физическая проверка, исчерпывающая оптимизация мягких переходных весов, самостоятельное исследование передачи и подмены пальцев. Ни одно изменение алгоритма из отчёта не внедрено.
