# Музыкальная запись

Для всех 62 нот сопоставлены ID исходного события, такт, позиция, staff, voice, MIDI, длительность, рука, лиги, артикуляция и авторский палец из импорта. Для каждой ноты указаны удержания, включая начавшиеся в прошлом такте. Реестры отражают фактические границы физического контакта отдельно от границ сегмента нотной записи. Модель назначает руку по staff и интерпретирует длительность контакта по исходным данным. Физическое действие требует дополнительной интерпретации исполнителя.

В Time нет маркировки педали и лиг. В No Surprises найдено 132 tie-маркера и нет педальной маркировки. В тактах 41 и 45 Time отдельные повторные атаки MIDI 60 идут в голосе 5, правая рука держит MIDI 60 в голосе 1. На этих событиях нет лиг, артикуляции и авторских пальцев.

Для каждой из 39 подписей есть синтетическая схема, выгружаемый MusicXML для традиционного представления, таблица нотных и физических интервалов и визуализация штатным Renderer. Схемы нормализуют высоту до условного MIDI 60, а длительности соседей берутся из модели. Полный нотный контекст реальной партитуры в материалах отсутствует.
