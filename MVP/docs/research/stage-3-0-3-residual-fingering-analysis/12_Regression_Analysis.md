У всех четырёх карт ноль конфликтов полной совместной проверки. При сохранении той же карты суммарные практические расширения и эргономические веса неизменны. Ослабление фильтров не может увеличить уже полное покрытие, а сохранение карты оптимально по числу изменений. Контактные контрфактические модели на регрессии отдельно не прогонялись.
