Синтетические схемы 39 контактных паттернов

Диагностические реконструкции сведены к относительным интервалам. Это не выписки оригинальных партитур. Строка «Цель» соответствует пропущенному контакту. В MusicXML для цели отдельно показана длительность исходного сегмента, а контакты — в таблице. Размер и абсолютная высота выбраны для демонстрации.
