# Повторяемость паттернов

17 относительных подписей Time и 22 No Surprises, всего 39. Подпись состоит из руки, длины контакта и относительного MIDI и границ удерживаемых соседей. 62 ID дают 23 дополнительных вхождения относительно одного представителя каждой подписи. Две подписи No Surprises содержат по пять исходных сегментов.

Подпись полезна для диагностики, но не утверждает идентичность полной фразы. Абсолютная высота, тип клавиши, артикуляция и переходы между непересекающимися контактами не входят в ключ. Разные сегменты одной лиги могут иметь одну подпись. Повтор тактов 41/45 Time даёт одинаковый набор межручных столкновений на MIDI 60 с разницей позиции 16 Q.
