# Переназначение B01–B05

| Режим | Допустимая область замены пальцев | Time | No Surprises |
| --- | --- | ---: | ---: |
| B01 | Пальцы всех сохранённых назначений зафиксированы | 523* | 1067 |
| B02 | Общие начала с пропущенными контактами | 523* | 1067 |
| B03 | Удержания, пересекающиеся с пропусками | 523* | 1067 |
| B04 | Связанная компонента интервалов целиком | 523* | 1067 |
| B05 | Любой автоматически назначенный палец | 523* | 1067 |

* Позволено оставить контакт неназначенным. В буквальном B01 с обязательным сохранением всех прежних назначений Time недопустим из-за двух исходных пересечений, No Surprises остаётся 1067. В B02–B05 смена пальца также не устраняет два совпадения ключа. Для Time во всех пяти диагностических режимах максимум достигается с 20 новыми назначениями, 10 снятыми и 0 заменёнными пальцами. Точное ранжирование минимизирует общее число изменений от базы, в том числе снятие, затем число и величину практических расширений. Полная взвешенная стоимость переходов production отдельно не оптимизирована.

B04 и B05 совпадают, потому что любое изменение в валидной независимой компоненте без пропусков увеличивает число правок и не увеличивает покрытие.
