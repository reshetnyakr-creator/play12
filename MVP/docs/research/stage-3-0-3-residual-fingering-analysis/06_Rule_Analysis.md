# Чувствительность к правилам

| Временно снятый фильтр | Time | No Surprises |
| --- | ---: | ---: |
| Ни один | 523 | 1067 |
| MaxPrac | 535 | 1099 |
| Октава | 527 | 1067 |
| Владение клавишей | 529 | 1069 |
| MaxPrac и октава | 535 | 1099 |
| MaxPrac и владение | 541 | 1101 |
| Октава и владение | 533 | 1069 |

Идентичный максимум при отключении октавы в No Surprises указывает, что на этой карте она не ограничивает суммарное покрытие. В Time октава блокирует прирост 4 в отдельной абляции, при снятии MaxPrac её влияние на максимум исчезает. Взаимодействие ограничений важнее суммы отдельных эффектов. Отключение владения — вычислительная диагностика невозможного исполнения. Изменение профиля не предложено.

MaxComf ранжирует допустимые карты. MaxPrac и ориентация октавы — жёсткие ограничения. Порядок пальцев в основной реализации — взвешенный штраф, в лабораторной модели он не введён как дополнительный запрет. Сложность переходов и подмена не выводятся из этой таблицы.
