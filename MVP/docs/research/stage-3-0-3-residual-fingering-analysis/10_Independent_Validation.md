# Метод валидации

Для каждой связной компоненты учитываются два типа рёбер: пересечение контактов одной руки и пересечение одной физической клавиши независимо от руки. Кандидаты 0–5. Фронт хранит пальцы ещё активных интервалов; состояния с одинаковыми активными пальцами объединяются по лексикографическому критерию. Уход из фронта возможен только на конце контакта. Ноты лиги имеют общий результат по ID контакта. Контактный план базовых экспериментов не переписывается.

Контроль отдельно перечисляет пересекающиеся пары готовой карты. Учитываются совпадение MIDI, занятость пальца, ориентация октавы и MaxPrac. На 15 малых синтетических наборах DP сопоставлен с полным перебором всех карт. На основных опытах бюджет не исчерпан. Доказательство максимума относится к объявленным интервалам и парным ограничениям. Биомеханика, подмена пальца и слышимый результат не охвачены.
