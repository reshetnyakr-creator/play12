# Научные и педагогические основания

| Ограничение | Основание | Предел доказательств |
| --- | --- | --- |
| Одно независимое нажатие на физическую клавишу в интервале | Свойство механики единственной клавиши. Разные голоса могут адресовать одно действие, если запись совместима с этим. | Не определяет фактическую минимальную паузу переатаки и поведение конкретного инструмента. |
| Один палец на разные удерживаемые клавиши | Рабочий контракт базового профиля. | Особые исполнительские приёмы не представлены. |
| MaxComf и MaxPrac | Parncutt et al. используют парные интервалы для мелодических фрагментов. | Перенос на плотную полифонию и универсальные пороги для начинающих не доказан. |
| Жёсткие пальцы октавы | Педагогический выбор Play12. | Ни взятые диапазоны, ни работа об индивидуации пальцев не доказывают универсальный запрет иных сочетаний. |
| Длительность контакта из XML | Воспроизводимое алгоритмическое допущение. MusicXML отдельно описывает длительность, атаку и снятие. | Нужны отдельные свидетельства исполнения для педали, передачи и подмены. |

Parncutt et al. ограничивают исходную модель мелодическими фрагментами. Furuya и Soechting исследуют координацию пальцев у подготовленных пианистов. Систематический обзор биомеханики обсуждает коартикуляцию. Эти исследования не валидируют новую карту для начинающих. Nakamura et al. показывают иной подход с вероятностным моделированием и аннотированными данными, полезный для внешней оценки альтернативных карт.
