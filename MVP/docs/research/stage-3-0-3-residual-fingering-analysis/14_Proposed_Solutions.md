# Предлагаемые исследовательские выводы

1. Сделать видимой в диагностике разницу между покрытием и строгой совместимостью обеих рук. Для проверенной карты Time 523 требуется разрешение оставить 10 прежних контактов без пальца при 20 восстановленных.
2. В первую очередь исследовать снятие и возврат на MIDI 60 в тактах 41 и 45. Проверять сохранение звучания и факт отдельной атаки. Для No Surprises проверять два самоповтора отдельно от интервалов.
3. Сохранить MaxPrac и правило октавы для начинающих до исполнительской проверки. Рассмотреть расширенный профиль только после определения целевой аудитории и проверки педагогического эффекта.

Модель с ранним снятием ещё не обосновывает изменения. Итоговый Renderer для неназначенных нот остаётся отдельным вопросом.
