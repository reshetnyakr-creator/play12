Позиции Q от начала. Правая начинает на 1–3 четверти раньше. Левые атаки в разных позициях самостоятельны по записи. При неизменной длительности контактов смена пальцев не устраняет конфликт: клавиша физически занята. Исключение прежней правой аппликатуры в строгом свидетеле не удаляет правую ноту из партитуры. Чтобы назначить обе руки с сохранением этих повторов, нужна модель освобождения и подтверждение слышимой длительности.

Полная проверка карты установила два конфликта в Time и ноль в No Surprises. Четыре пары из ТЗ — дополнительные столкновения, которые возникли бы при возврате четырёх левых назначений без изменения плана.
