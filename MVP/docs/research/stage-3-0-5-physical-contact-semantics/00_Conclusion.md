# Stage 3.0.5 — контрольная точка §10

Все восемь G1/G2 — отдельные разновременные атаки. H1 относится ко всем восьми. H2 не объясняет ни один из восьми случаев. В тактах 51 и 53 No Surprises исходный MusicXML не содержит ни одной пары с одним MIDI и одинаковым началом. Для MIDI 48 первый голос начинает на 1,5 четверти раньше второго, а записанные длительности составляют 2 и 0,5 четверти. В такте есть и последующие атаки, включая атаку первого голоса на границе 202/210 Q.

H1 частично уже предусмотрен R11/R12/R55 и реализован для ограниченных педальных переходов Stage 1.4. По всем восьми раннее освобождение при проверенных условиях отвергнуто действующим планировщиком. Для автоматической обработки данных без подтверждённого плана нужно явное согласование расширения. H2 для одной руки предусмотрен R05 и действительно реализован в Stage 1.5. H2 для двух рук нуждается в явной политике физического исполнителя, согласованной с R39. Новые номера правил не требуются.

| Карта | Time | No Surprises |

| Проверка текущего кода | 523/541, принятых новых контактов 0 | 1067/1101, принятых новых контактов 0 |
| После расширения H1/H2 | Не измерялось | Не измерялось |

Влияние на G3/G4 в проверенном плане равно нулю. При смене плана оно потребует совместного пересчёта соответствующих компонент, см. матрицу зависимостей Stage 3.0.4. Физическая проверка не проведена.
