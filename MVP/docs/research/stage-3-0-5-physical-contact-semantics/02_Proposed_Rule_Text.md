# Редакции для согласования

## H1 — дополнение R11/R12/R55

«Для каждой самостоятельной более поздней атаки одной физической клавиши план обязан явно указать окончание предыдущего физического контакта и достаточный возврат по калибровке инструмента. Проверка общая для рук и голосов. Записанные атаки, длительности и лиги сохраняются. Раннее окончание контакта допускается только при указанном основании снятия и отдельно подтверждённом сохранении музыкально требуемого звучания. При отсутствии любого из этих фактов результат — unknown, буквальный контакт сохраняется. Значение reset не подставляется из универсального порога. Смена руки между атаками не меняет руку исходного события».

T14/T15/T67/T68: противоположная рука и тот же MIDI, проверка ненулевого окна либо unknown, проверенное сохранение звучания, отказ при лиге и неподтверждённом снятии. T01/T41/T47: сохранение событий, рук и ручных назначений. Последствие: проверка полного потока клавиши перед принятием карты; изменение контакта влияет на соседние занятости в G3/G4. Согласовать, какие данные принимаются как подтверждение снятия и звучания при отсутствии указания педали.

## H2 — дополнение R05 с явной границей R39

«Совместимые одновременные события с одним MIDI и равной записанной длительностью могут разделять один контакт при совпадении исполнительской семантики. Для разных рук общий контакт допустим только в явно включённом согласованном режиме. Назначить физическую руку и палец в плане контакта, оставив исходные hand, voice, staff, события, времена, длительности и ручные указания неизменными. Предпочесть допустимого исполнителя по существующим оценкам положения и переходов. Отдельные атаки, разные длительности и конфликтующие ручные ограничения остаются самостоятельными; при неоднозначности вернуть unknown».

T07/T41/T45/T47/T67: оба возможных исполнителя, задержка/разная длительность, несовместимые ручные указания, стабильность одного контакта на исходные ID, отсутствие скрытого переноса, одинаковое поведение при зеркальном обмене рук с эквивалентной геометрией. Отдельно проверить отображение исходных голосов и фильтры режима одной руки. Согласовать, допустим ли исполнитель контакта, отличающийся от руки одного из исходных событий. Для восьми текущих случаев этот механизм сам по себе не даёт прироста.

Обе редакции являются предложениями. Изменения правил, генерация экспериментального исполнителя и выпуск карты остановлены до согласования.
