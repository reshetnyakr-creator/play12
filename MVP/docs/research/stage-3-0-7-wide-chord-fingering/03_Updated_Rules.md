# Уточнённые правила

| Правило | Прежнее | Эксперимент |
| --- | --- | --- |
| R07 | MaxPrac, с отдельным допуском направленной пары 1–5. | Внутри полного одновременного широкого аккорда согласованного строения допускается парное превышение. Оно отмечается по каждой паре. |
| R14 | Ранжировать допустимые варианты по существующим параметрам комфортности и стоимости. | Прежние параметры применяются к промежуточным пальцам и контексту. |
| R30 | Проверять все перекрывающиеся пары. | Сохраняется проверка каждой пары. Аккордовое исключение действует только между членами целого аккорда, не с соседним удержанием. |
| R37 | Направленные крайние пальцы обязательны для октав. | Та же ориентация используется для внешних нот широкого аккорда. Октавные и остальные ограничения остаются. Промежуточные пальцы строго следуют высотному порядку. |

Новых номеров правил и значений MaxPrac/MaxComf нет. Если клавиш больше пяти, движок не назначает два одновременно занятых контакта одному пальцу.
