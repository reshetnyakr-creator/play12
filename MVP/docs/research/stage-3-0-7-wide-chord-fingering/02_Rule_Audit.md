# Аудит действующих правил

Исходный аудит Stage 3.0.6 описывает ограниченный пересмотр прямых соседей и эпизоды, где он не формирует целый аккорд. В ядре остаётся отдельная проверка одинаковой клавиши, занятого пальца, обычного MaxPrac и направленной октавы. Обновление исходит из согласованного изменения R07/R30/R37 и сохраняет R14.

| Область | Ограничение | Проверка |
| --- | --- | --- |
| R07/R14/R30 | MaxPrac остаётся жёстким вне двух согласованных исключений, MaxComf остаётся критерием оценки. | Ранжирование, таблицы и геометрия профиля не менялись. Все пары проверяются. |
| R37 | У октавы направленные крайние пальцы обязательны. | Октава внутри широкого аккорда тоже проверяется. |
| R04/R05/R09 и Stage 3.0.5 | Один палец на одновременно удерживаемую клавишу, роли контактов, лиги и переатаки сохраняются. | Старт и конец контактов берутся из воспроизведённой карты. Недопустимые пересечения не принимаются. |
| R39/R45/R47/R58 | Руки остаются заданными. Ручные пальцы сохраняются. | Ручные ограничения и восемь пальцев Stage 3.0.5 заморожены. |
| Stage 3.0.6 | Сверх MaxPrac в последовательности с перекрытием допускается направленная внешняя пара 1–5. | Допуск внутренних пальцев для разных атак не добавлялся. |
