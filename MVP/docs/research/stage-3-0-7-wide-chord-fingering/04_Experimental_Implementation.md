# Экспериментальная реализация

Исследовательский проход стартует с карты Stage 3.0.6. Аккорд определяется по полному набору самостоятельных атак одной руки с одинаковым исходным и контактным началом. Требуются разные клавиши, три или более членов и крайний интервал сверх MaxPrac 1–5. Случаи с более чем пятью членами получают явный отказ. Продолжения лиг не считаются новыми атаками.

Поиск сначала пересчитывает все пальцы аккорда. Крайние пальцы заданы направлением, внутренние выбираются из 2, 3 и 4 и строго следуют высотному порядку. При неудаче область расширяется на транзитивную компоненту перекрывающихся контактов той же руки либо той же физической клавиши. За основу взяты интервальный поиск, критерии и веса Stage 3.0.6. Сохранение количества исходных назначений обязательно. При равном покрытии сохранение существующих пальцев имеет приоритет, затем применяются прежние оценки MaxComf и формы. Для последовательного случая пересчитывается та же компонента, а парный допуск остаётся в границах Stage 3.0.6.

Валидатор заново проверяет результат. Аккорд принимается только целиком с направленными крайними пальцами и строгим порядком. Полный список пар включает ID всех музыкальных сегментов, руку, MIDI, пальцы, интервалы, пороги и превышения. Результат R37, повторное использование пальца и чужое удержание сохраняют прежний статус.

Расчёт последовательно проверяет исходные пропуски и сохраняет каждое уже включённое событие. Для одиночной проверки текущей цели другие пропуски активируются только как члены того же аккорда. Глобальный поиск с обменом ранее назначенных нот или с новым исполнительским планом не выполнялся. Worker, штатный импорт и редактор экспериментальный режим не включают.
