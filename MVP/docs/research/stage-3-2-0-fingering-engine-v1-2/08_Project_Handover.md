Из корня репозитория запустить команды из тестового отчёта и node MVP/docs/research/stage-3-2-0-*/scale.cjs. compare.cjs принимает шесть локальных параметров в порядке Time и No Surprises (снапшоты Stage 3.0.10), прежний JSON контроля Time, затем импортированные JSON для Clocks, Interstellar и Saints в обёртке с полем score.
