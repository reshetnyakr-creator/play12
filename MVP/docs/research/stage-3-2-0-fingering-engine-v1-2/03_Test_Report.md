# Отчёт о тестировании

Регрессия Node: MVP/tests и исследовательские тесты Stage 3.0.5–3.0.10, вместе с 12 новыми проверками ядра. Команда из корня:

~~~sh
node --test MVP/tests/*.cjs MVP/docs/research/stage-3-0-{5,6,7,8,9,10}*/*.test.cjs MVP/docs/research/stage-3-2-0-*/*.test.cjs
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s MVP/tests -p 'test*.py'
PYTHONDONTWRITEBYTECODE=1 python MVP/docs/research/stage-3-0-3*/test_research.py
~~~

Новые исполняемые проверки охватывают неизменность источника, ручные блокировки, зеркальную гаммовую позицию, полную занятость при удержаниях и полуоткрытых границах, шесть одновременных клавиш, запрет E08/R35 при любых допустимых остаточных весах, выход из диапазона широкой тройки, октавы обеих рук, неизменность статуса неизвестной физики, исчерпание бюджета, E07 при удержанном басе, два контакта одной клавиши и повреждённый результат. Контрольные референсы Time и доказательства повторов исполняются отдельно через compare.cjs. Нормативные описания и имеющиеся регрессии не засчитывались автоматически в полное покрытие новых контрактов.

| Набор | Фактически выполнено новым ядром |
| --- | --- |
| T01–T72 | Целевые проверки пересекаются с T01, T05, T06, T08, T11, T36, T37, T39, T45, T53, T56, T65, T67. Полной приёмки отдельных контрактов нет. |
| M01–M30 | Использованы сценарии, эквивалентные отдельным условиям M01, M02, M09, M10, M15, M16, M19, M20. Полный оригинальный пакет не исполнялся. |
| A01–A24 | Основные утверждения A01–A05, A10, A15, A17–A20, A22, A24 проверялись отдельными нагрузками. В остальных, а также в перечисленных непроверенных мутациях и точных предусловиях, покрытие неполное. |
| Проверка моделей | Нет калиброванных физических или акустических тестов. Результаты по обеим категориям unknown. |

Прототип не соответствует требованию о полном наборе T/M/A и не объявлен принятым.

Итог прогона: 445/445 Node, 9/9 Python unittest, 15/15 сценариев Stage 3.0.3. Отдельно успешен запуск сравнения на пяти композициях в заявленных режимах. Полный корпус без подготовленных планов для всех произведений не принят. [Сравнительный отчёт](04_Musical_Comparison.md).
