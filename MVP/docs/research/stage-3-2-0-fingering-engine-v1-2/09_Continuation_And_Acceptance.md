# Контрольная точка и статус приёмки

Входной коммит 21ed7f18dd40e7b88d2991775421cf338cdade0d. Продолжение Stage 3.2.0. Нормативный пакет 14c69c5391a60f81e1c97c17723a8c5f00d3517a применён без поправок.

## Причина блокировки Time 38

| Нотное событие | MIDI | Атака | Конец в нотах | Конец прямого физического плана | Конец исторического плана |
| --- | ---: | ---: | ---: | ---: | ---: |
| P1.m37.e7 | 36 | 148 | 152 | 152 | 149 |
| P1.m37.e8 | 43 | 148 | 152 | 151½ | 149 |
| P1.m37.e3 | 52 | 148 | 149 | 149 | 149 |
| P1.m37.e4 | 57 | 149 | 150 | 150 | 150 |

Прямой план сохраняет оба нижних контакта на новой атаке. Начальная широкая тройка имеет направленную форму 5–2–1. При MIDI 36 под пальцем 5 назначить MIDI 57 можно только большим: для 2–4 расстояние 21 превышает MaxPrac. Между удерживаемым MIDI 43 под пальцем 2 и MIDI 57 под пальцем 1 получается ещё 14 при MaxPrac 1–2 = 10. Отдельный полный перебор четырёх контактов посетил 8 вариантов до отказа на 149. Это локальный отказ внутри текущей модели. Педальных указаний в исходном файле нет. Снятие обоих нижних контактов на 149 даёт расчётные 541/541, но акустическое удержание до 152 не подтверждено.

Исторический Stage 3.0.8 предлагает символическую границу освобождения как исследовательскую гипотезу. Для прямого рабочего импорта отсутствует подтверждённое основание E03, позволяющее считать эту границу физически и музыкально пригодной. Повторное использование функции прежнего пересчёта также не сняло расхождение: для цели P1.m37.e4 тот алгоритм вернул assigned_without_release, а новый поиск с ограничениями совместной формы по-прежнему отверг слой. Автоматически переносить исторические границы или отпускать клавиши при первом отказе опасно для смысла нотной записи и противоречит текущему заданию.

**Решение автора требуется только для условия E03 на этом участке.** Можно сохранить заданное удержание и принять неполное назначение либо отдельно определить, какие сведения об исполнении и звучании достаточны, чтобы этот контактный вариант стал допустимым при прямом импорте. Без решения ни предписанное удержание, ни обязательные пределы не ослабляются.

## Изменения этой контрольной точки

- Добавлен воспроизводимый вход MusicXML/MXL через штатные модули импорта. Сохранённые планы используются отдельно для сравнения.
- E05: перебор обычной формы и проверка раздельных позиций. При доказанном отсутствии обычной формы общий механизм обнаруживает Time 46 сразу при прямом импорте. Нотная атака и обе позиции сохранены, время движения и звучание остаются unknown.
- E07: отдельный перебор без веса и без вызова search.cjs. Для каждого повторного ребра проверяется его присутствие в результате и исчерпание поиска при запрете соответствующего повтора. Нулевой бюджет, отсутствующее доказательство и доступная альтернатива приводят к отказу верификации.
- Верификатор E05 проверяет идентичность событий, высоты, пальцы и ограничения внутри каждой отдельной позиции. Модель не утверждает интервал физического движения между позициями.

## Критерии готовности

| Критерий | Статус |
| --- | --- |
| 1. Прямой конвейер без сохранённых планов | Выполнен как путь запуска. Полнота Time заблокирована на 149, четыре остальных прямых импорта полные. |
| 2. Обязательные правила | Частично: полная общая комфортная поза и семантические музыкальные группировки отсутствуют. |
| 3. Независимая проверка L0 | Прогон опубликован. Ноль найденных нарушений для выданных назначений. Неполный результат Time этим не считается принятым. |
| 4. Запрещённые PRO-приёмы | Пройдены проверки E08/R35, включая изменение весов. |
| 5. Time 38/46 | 38 проходит только на историческом контактном плане. 46 проходит прямой импорт автоматически. |
| 6. Тестовые контракты | Регрессия и новые целевые проверки пройдены. Полное покрытие применимых контрактов открыто. |
| 7. Пределы поиска, движения, акустики | Бюджет и infeasible различены. Инструментальных проверок не проводилось. |
