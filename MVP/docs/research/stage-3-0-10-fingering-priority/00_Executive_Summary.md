# Stage 3.0.10 · Кандидат до согласования

Обязательный последовательный приоритет выполняется до сравнения весов. На оригиналах после пересчёта Time имеет 541/541 назначенных пальцев, No Surprises — 1101/1101. У аккорда Time 46 все три пальца имеют обычный статус назначения. Смена позиции хранится как отдельная диагностическая отметка, без назначения времени атак.

Контроль Time 38 не закрыт. Авторские 5–2–1 | 2–3–4 допустимы и дают ноль повторов в продолжении. При полном пересчёте действующая оценка выбирает **5–2–1 | 2–3–1**. Требование автоматически получить авторский вариант остаётся открытым. Этот результат сохранён как кандидат для согласования. Продуктовая аппликатура не менялась.
