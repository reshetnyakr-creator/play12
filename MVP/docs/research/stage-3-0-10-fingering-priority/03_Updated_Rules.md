# Согласованные уточнения

- R22. Среди решений со всеми жёсткими ограничениями сначала сравнивается число повторов пальца на разных последовательных клавишах. Веса сравнивают решения после этого шага. Одна клавиша, защищённая ручная пара и доказанное отсутствие варианта с нулевым повтором отделяются в диагностике.
- R07/R14/R30/R37. В одновременном широком трезвучии от мизинца до внутреннего пальца проверяется MaxComf, от внутреннего пальца до большого — MaxPrac. Первым рассматривается второй палец. Исключение действует только для направленной внешней пары 1–5.
- R07/R09/R12/R37/R40. Если совместное нажатие невозможно, разрешена аппликатура с несколькими позициями. Внутри каждой позиции действует MaxPrac и направленная октава. Между раздельными позициями нет теста совместного размаха. Разделение субъективной техники и фактического тайминга сохраняется.
- R44/R45/R53/R56. Полноценный палец и необходимость специального приёма являются разными полями. Тайминг и звук могут быть неизвестны. Ручное значение остаётся выше автоматического выбора. Исчерпание бюджета остаётся явной неопределённостью.
