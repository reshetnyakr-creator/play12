# Экспериментальная реализация

Перед расчётом воспроизводятся назначения, диагностические категории и физические интервалы Stage 3.0.9. Обе руки пересчитываются по всем сохранённым атакам соответствующего физического плана. Совпадение времени образует слой. Последовательная пара определяется между соседними слоями руки при двух одиночных атаках либо при единственной ноте одного и того же голоса в каждом из двух слоёв. Отдельные атаки одной клавиши исключаются. Связи с аккордом, чьё физическое время исполнения не задано, не получают искусственного порядка.

Динамическое программирование хранит назначение продолжающихся контактов и пальцы последнего слоя. Таким образом, оно сравнивает все пути, которые отличаются далее по ограничениям. В первую очередь минимизируется число повторов пальца на смене клавиши. Далее сравниваются число и сумма превышений MaxComf, действующие оценки формы, движения, порядка и повторения, затем число отличий от начальной карты. Коэффициенты не менялись. Исчерпание бюджета не записывается как отсутствие альтернативы.

Внутри позиции все физические пары проверяются с реальными пределами. Для аккорда со сменой позиции перебираются разбиения без наложения, предпочтение имеет направленная крайняя пара и внутренний палец 2. В пределах позиции проверяется MaxPrac. За пределами позиции нет сравнения как одновременного удержания. Для такта 46 факт невозможности общей атаки уже доказан полным перебором Stage 3.0.9. События имеют статус `assigned`, исполнительский приём и неизвестное физическое время хранятся отдельно. Рабочий интерфейс и транзакции редактирования не менялись.

Для аккордов с уже разрешённой перестройкой удержаний локально проверены все варианты последующей короткой группы. Разные физические планы отданы на полный пересчёт. Основной счётчик до и после использует те же связи между слоями. Формальные исключения и все оставшиеся повторы перечислены в реестре. Порядок расчёта рассчитан для профиля «Начинающий», старые пути запуска остаются прежними.
