# MaxComf, MaxPrac и октавы

Для каждого слоя перечислены все инъективные сочетания пальцев (до 120), включая исходно удерживаемые контакты. Проверены все пары, взаимное исключение клавиш и пальцев, MaxComf либо MaxPrac и правило октав 5–1 слева, 1–5 справа. Сравнение с выключенной октавной проверкой проведено исключительно для локализации причины.

| Слои | Time | No Surprises |
| --- | ---: | ---: |
| Нет форм даже без октавного правила | 16 | 27 |
| Нет форм с октавным правилом, есть без него | 6 | 0 |
| Повторная атака удерживаемого MIDI | 2 | 2 |
| Пропущены восстановлением при наличии практических форм | 14 | 58 |
| Отдельно вызваны исчерпанием пяти пальцев | 0 | 0 |

В CSV свободные пальцы и индивидуальные отказы относятся к сохранённым активным назначениям. Поле shapes снимает это фиксирование и считает формы целого слоя. На полном временном горизонте проверена возможность назначить подмножество без разрыва удержаний. Порядок пальцев и геометрия клавиш участвуют в ранжировании. Самостоятельных жёстких отказов по ним не выявлено.
