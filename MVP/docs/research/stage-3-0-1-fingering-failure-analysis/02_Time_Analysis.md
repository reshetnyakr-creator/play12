# Time — 72 ноты без аппликатуры

541 исходная нота дала 541 контакт. Пропуски затронули 71 контакт левой руки и один правой, всего 38 слоёв.

| Код | Ноты | Конкретное препятствие |
| --- | ---: | --- |
| C05 | 38 | Раунд 47, Q=185. Удерживается MIDI 43 на пальце 5 до Q=188, MIDI 59 отстоит на 16 полутонов при максимуме 15. Соседний MIDI 57 допустим отдельно, но теряет палец вместе со всей атакой. |
| C06 | 15 | Раунд 46, Q=180, MIDI 48/59/60. Октава 48–60 фиксирует 5–1 слева. Промежуточному MIDI 59 нужен один из пальцев 2–4, ни одна из этих пар с пальцем 5 не покрывает 11 полутонов. Ноль форм с правилом, шесть при диагностическом отключении только октавного условия. |
| C03 | 2 | Раунд 31, Q=122. Правая рука повторно атакует MIDI 59, который контакт P1.m30.e0 удерживает до Q=124. Второй случай — P1.m33.e5 слева в Q=135. |
| C19 | 17 | После отказа Q=180 граница восстановления Q=184 подавляет шесть следующих нот раунда 46. На этих отдельных слоях есть допустимые формы. |

Раунды 46–49 содержат 9, 8, 6 и 0 пропусков. В раунде 48 бас MIDI 38 удерживается до Q=192, MIDI 54 в верхнем голосе даёт интервал 16. Оба голоса находятся в левой руке по разметке нотоносцев. Смена руки не входила в расчёт.

Восстановлены в независимой карте 48 нот: 22 из C05, 9 из C06 и все 17 из C19. Все 469 существующих пальцев сохранены. 24 ноты остаются вне найденного максимума.
