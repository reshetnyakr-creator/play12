# Совместимый максимум частичного восстановления

Независимое DP хранит палец каждого ещё удерживаемого контакта. После окончания удержания эквивалентные состояния объединяются. Все ранее назначенные контакты обязательны, неназначенные могут получить палец или остаться без него. Цель — число восстановленных исходных сегментов, затем сохранение ранее назначенных пальцев, затем число восстановленных контактов. Для итогового свидетельства повторно проверены все пересечения. При фиксации каждого прежнего пальца максимум совпал.

| Измерение | Time | No Surprises |
| --- | ---: | ---: |
| Исходные пропуски | 72 | 120 |
| Совместимый максимум | **48 нот / 48 контактов** | **86 нот / 70 контактов** |
| Восстановлены в первичных группах C05/C06 | 31 | 16 |
| Восстановлены в каскаде C19 | 17 | 70 |
| Остались вне максимума | 24 | 34 |
| Необходимо менять прежние пальцы | 0 | 0 |
| Прирост при расширении луча | 0 | 0 |

Частичный результат сохраняет все ноты и длительности в партитуре. Контакт, оставшийся без пальца, в проверке не претендует на занятый палец или клавишу. Это точный предел на принятом плане, без оценки удобства переходов и физической выполнимости всей исходной музыки. Не выбранные ID могут входить в альтернативный максимум.

Луч 256 дал 1847 и 2525 мс в отдельном Node-прогоне. Для переноса частичного поиска потребуется отдельно сохранить приоритет MaxComf и оценить стоимость переходов и бюджет. Для четырёх повторных атак нужен подтверждённый способ снятия удержания, прежде чем обсуждать другой контактный план.
