# Поиск и локальное восстановление

Worker запускает proposeBeginner. Ядро перебирает пальцы по onset отдельно для каждой руки. Удерживаемые контакты фиксируют занятые пальцы. Повтор удерживаемой клавиши блокирует слой до перебора. Ранжирование учитывает число пар сверх MaxComf, сумму превышений и взвешенную стоимость формы, движения, смены пальца, перекрещивания и досягаемости. Луч сохраняет разные пальцы на ещё удерживаемых контактах.

| Параметр | Значение |
| --- | ---: |
| Луч | 64 |
| Кандидатов на слой, максимум | 100 000 |
| Поиск / Worker | 12 / 25 с |
| Сгенерировано Time / No Surprises | 367 025 / 508 405 |
| Усечено по ширине луча | 101 884 / 208 472 |

Лимит времени и SEARCH_EXHAUSTED в двух импортированных картах не сработали. Изолированный луч 256 с бюджетом 30 с дал тот же набор пропусков. Допустимых полных слоёв среди первичных отказов исчерпывающий перебор не обнаружил.

Stage 1.3 при отказе полной атаки сохраняет префикс, отвергает весь слой и ждёт recoveryEnd. Пропущенная в период ожидания атака, в том числе лигованная, может продлить границу. Это механизм 92 пропусков C19. Альтернатива проверена на неизменном плане отдельным DP, см. [расчёт](09_Recovery_Experiments.md) и [Stage 1.3](../../fingering-stage-1-3.md).
