# Проект новых тестовых контрактов

Синтетические входы задаются в рациональном времени. Если числа называются в миллисекундах или миллиметрах, они относятся к тестовой калибровке. Для каждого зеркального случая инвертировать руку и направленный порядок. Проверять окончательного победителя и trace исключённых путей.

| ID | Вход | Обязательный результат | Контрольная мутация |
| --- | --- | --- | --- |
| A01 | Два законченных пути, один нарушает физический lock или занятость, другой дороже | Выигрывает физически допустимый путь. Хеш партитуры и ручной слой совпадают. | Стоимость физически недопустимого пути обнулить. |
| A02 | Две разные клавиши по очереди, в одной компактной позиции доступны разные пальцы. Дешёвый путь повторяет палец | R22 блокирует дешёвый путь. Отрицательная стоимость не влияет. | Веса ×1000 и состав соседней группы с равным выходом. |
| A03 | Удержание дальнего голоса запрещает все разные пальцы | При полном поиске задокументировано E07 с ID удержания. | Снять удержание на границе атаки и повторить. |

| A06 | A05 плюс зависимое удержание следующей группы перекрывает естественное продолжение | Допускается смена позиции с доказательством отсутствия остаточного пути. | Удержание укоротить на условную единицу. |

| A12 | Два фронтира с одинаковыми текущими пальцами и разной будущей областью | Поиск удерживает оба, выбирает продолжаемый путь, след объясняет различие. | Мутация ключа фронтира удаляет нужный путь. |

Контракты подлежат рассмотрению вместе с [решениями автора](16_Author_Decision_Register.md). Проверку A02–A07 не закрывает совпадение с авторским пальцем в одном такте. Для A05 нужны обобщающие формы, отличающиеся набором чёрных клавиш и направлением.

## После решений автора

A07 проверяет совместный фильтр: если есть путь, удовлетворяющий позиции и R22, нарушающие один из критериев не достигают L4. Если полный перебор искусственного примера даёт только взаимоисключающие классы, вывести оба свидетеля и неопределённый статус, без нового автоматического исключения.

| ID | Контроль | Оракул и отрицательная проверка |
| --- | --- | --- |
| A17 | Time 38 без закрепления целевых пальцев | 5–2–1 / 2–3–4. 1–2–3 исключён по входу R22, 3–4–5 по R18, 2–3–1 по порядку. Мутировать веса и тактовую границу. |
| A18 | Time 46 | Три assigned, две позиции, исходная одновременность, физическое исполнение unknown. В одной позиции внутреннюю недопустимую пару отвергнуть. |
| A19 | 48 повторов и 68 широких пар | Поштучная проверка и зеркало рук. Включить новые совместные атаки при отсутствии предыдущих удержаний. |
| A20 | RH C♯4+C♯5 и LH A3–G3–F♯3 | 1–5 в допустимой октаве, 2–4 на чёрной в естественном контексте, существующий lock сохранён. |
| A21 | Затакт, мотив через черту, удержание второго голоса | Нотная фраза не обрезается чертой; исполнительская область заканчивается при несовместимости позы или продолжения. |
| A22a / T36 | E08, передача удерживаемой клавиши другому пальцу | В «Начинающем» исключить кандидат до оценки. Проверить с допустимой обычной альтернативой и без неё, при любой выгоде L4. В PRO проверить сохранение одной атаки и непрерывность контакта. |
| A22b / T37 / M19 | R35, скольжение одного пальца на соседнюю клавишу | В «Начинающем» исключить кандидат до оценки, включая отсутствие и исчерпание поиска альтернатив, E06/E07 и произвольную стоимость. В PRO проверить обе нотные атаки и неприменимость к несоответствующему контексту. |
| A23 | Калибрована только W→B левой пары 2–4 | Иные пары, направления и RH остаются неизвестны. Независимые пользовательские совпадения дают исследовательский сигнал без правки правила. |
| A24 | Произвольный знак и масштаб L4 | Множество допустимых путей неизменно; при нечисловой оценке безопасно остановить оценку или технически сравнить внутри S. |

Это будущие тесты реализации. Диагностические скрипты Stage 3.1.0 проверяют свидетелей и целостность материалов.

## Уточнение E03 к A06 и A17

A06: сначала исполнить поиск с исходными удержаниями. При допустимом пути и при исчерпании бюджета освобождения отсутствуют. При доказанном отказе сопоставить варианты освобождения, восстановить каждый удерживаемый контакт по отдельности и проверить, что утверждённое продолжение теряется. Исходные события, длительности и педаль совпадают, статусы пальцев полноценны.

A17: импортировать исходный Time из MXL. Проверить 541/541, пальцы 5–2–1 / 2–3–4, отсутствие ручных блокировок целевых нот и отсутствие зависимости прямого прогона от сохранённого плана.
