# Оценка качества

Единицы измерения — событие, физический контакт, переход, зависимая группа и композиция. Сохранять версию профиля, хеш входа, калибровку и причины неоценённых эпизодов. Показатели по начинающим взрослым и детям собирать отдельно. Числитель каждого показателя сопровождается знаменателем применимых случаев.

| Группа | Показатель | Знаменатель и решение |
| --- | --- | --- |
| Приёмка L0 | Неизменность источника, locks, нарушения контактов, физических пределов, распределения рук | Вся партитура, все защищённые события и проверяемые позиции. Любое подтверждённое нарушение блокирует приёмку. |
| Педагогика L2 | Нарушения естественного порядка, применения разных пальцев и выбора на чёрных клавишах | Сопоставимые случаи с доказанной альтернативой. По каждому критерию отдельная доля. |
| Движение | Необоснованные перемещения, перекладывания, подкладывания, повторы пальца | Переходы с проверяемой альтернативой. События адаптации не считать перемещением. |
| Позиция | Избыточная растяжка и доля сохранённых комфортных позиций | Проверенные пары и группы. Результаты отдельно для модельных и измеренных областей. |
| Исключения | Число E01–E09 и доля с подтверждёнными условиями | Все активированные ворота. Считать неподтверждённые основания отдельными дефектами. |
| Последовательность | Согласованность совпадающих мотивов | Группы с эквивалентным входным и выходным контекстом. |
| Покрытие | Назначено, не назначено, вход не моделируется | Все музыкальные события и отдельно допустимые для расчёта. |
| Время и звучание | Возврат ключа, прерывание удержания, успешное акустическое продолжение | Только нуждающиеся в проверке контакты, отдельно число unknown. |

Независимые преподаватели оценивают слепые пары путей и могут отметить оба равноприемлемыми, указать конкретный тип затруднения или воздержаться. Разделять по композициям и аранжировкам, группировать повторные мотивы при разбиении, проверять оценщиков на расхождениях, сообщать согласие и разброс по группам. Инструментальная проверка включает фактический темп, видеонаблюдение и при доступности MIDI и измерение возврата. MIDI в одиночку не подтверждает нагрузку и удобство.

## Утверждённая приёмка (D06–D07)

Порядок оценки: ноль нарушений L0 → соблюдение применимых обязательных приоритетов → полное обоснование каждого исключения → обоснованность перемещений и сохранение комфортных поз → полнота. Охват не компенсирует нарушение. Корпус хранит допустимые варианты и проверяемые причины, без единственного универсального эталонного пальца.

Пользовательские корректировки в будущем анализировать по профилю, версии движка, сопоставимой фигуре, инструменту и ручным ограничениям. Дубликаты одного исполнителя/фрагмента объединять. Повторяющиеся независимые исправления в одном контексте дают исследовательский сигнал, который преподаватель проверяет на исходном фрагменте и отрицательных примерах. Результат проходит авторский пересмотр с записью версии. Автоматического изменения правил по статистике нет.
