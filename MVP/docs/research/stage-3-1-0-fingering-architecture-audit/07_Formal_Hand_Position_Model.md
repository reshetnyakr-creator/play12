# Формальная модель позиции

Клавиша определяется физическим ID и областью касания K(k) в координатах x вдоль клавиатуры, y в глубину. Белые и чёрные имеют разные доступные области. MIDI определяет высоту и помогает искать K(k). В core.keyX используется приближённый центр вдоль x.

Состояние руки хранит область опоры кисти A, диапазон ориентации Θ, активные контакты I и области достижимости пальцев F(h,f,θ). Для совместных контактов требуется общая пара (a,θ), где a∈A и θ∈Θ, такая что K(key(c)) и a+F(h,f,θ) пересекаются для каждого контакта. Длина, подвижность и направление включаются в F при наличии измерений. При отсутствии данных хранятся область модельной оценки, способ её определения и неопределённость.

Практический предел пары задаётся направленным MinPrac ≤ d ≤ MaxPrac с существующими контекстными исключениями. Для комфортного продолжения дополнительно нужны MinComf ≤ d ≤ MaxComf и общий свидетель для порядка и глубины. Нижние пределы не подставляются из нулевой гипотезы. Таблица Parncutt — исходная эргономическая гипотеза. Параметры модели Play12 должны оставаться версионированными.

Адаптация кисти внутри позиции возможна, если существует непрерывное движение опоры и ориентации в общей комфортной области всей группы с сохранением занятости. Смена позиции требует выхода из области или перехода между несовместимыми областями. Горизонтальный перенос, движение в глубину, вращение, подкладывание и перекладывание записываются раздельно.

На первом этапе области можно представлять дискретизированными интервалами, хранить совместимые ориентации на событиях начала и конца, проверять остаточные обязательства и совместимые выходы через следующую зависимую группу. Слияние состояний разрешено только при равных будущих обязательствах. Статус model_supported означает вычислительный свидетель в явно описанной модели. При неизвестном времени, диапазоне или глубине выдаётся unknown. Для physically_confirmed требуется внешняя измерительная проверка.
