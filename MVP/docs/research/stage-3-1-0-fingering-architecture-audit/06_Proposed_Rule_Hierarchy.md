# Иерархия применения правил

| Порядок | Проверка | Следствие |
| --- | --- | --- |
| L0 | События, руки и locks источника, допустимые номера пальцев, занятость, практические пределы всей позиции, неопределённость | Отбросить недопустимый кандидат. Ручные данные сохранить с отдельным конфликтом. |
| L1 | Независимо классифицировать музыкальные границы, контакты, тай, переатаки, октавы, гаммы, аккорды, арпеджио и специальные приёмы | Применять только условия подтверждённого контекста. В неизвестном контексте не использовать послабление. |
| L2 | По порядку ниже отбирать пути с допустимым продолжением. | Следующий критерий сужает только множество путей, прошедших предыдущий. |
| L3 | Проверять регламентированные ворота при применении соответствующего L0/L1/L2 | Ворота меняют только указанный предикат, а не решение остальных правил. |
| L4 | Сравнить оставшиеся варианты, сохранять техническую детерминированность по ID | Коэффициенты не возвращают отфильтрованный вариант. |

## Обязательный порядок L2

1. **Совместный фильтр R13/R14/R22/R24.** Проверить продолжение в общей естественной комфортной области и разные пальцы при переходе на другую клавишу, включая однозначные входное и выходное ребро. Применять оба требования совместно, если существует допустимый полный путь. Раздельный фильтр, удаляющий совместимо удовлетворяющий обоим критериям путь, запрещён. Отсутствие такого пути проверяется по каждому предикату. Для повтора пальца требуется E06/E07, для потери области — свидетельство отсутствия продолжения в ней или активированный ранее согласованный приём. Если найдены только взаимно исключающие пути, а ни одно исключение не доказано, вернуть оба с полной аппликатурой и описанием поз. В проверенном корпусе такой случай не подтверждён. Это статус незавершённого решения, а не новый приоритет и не исключение.
2. **Цепочка близких клавиш.** На непрерывной естественной группе узких последовательных расстояний при совместимом выходе предпочесть последовательные пальцы в естественном для направления порядке. На смене области и широком интервале это требование само по себе не действует. Определять применимость через контекст и общую модельную область, без порога по длине такта.
3. **R17/R18.** На чёрной клавише длинные 2–4 имеют преимущество при наличии естественной допустимой альтернативы после предыдущих проверок. Нормативная форма октавы/аккорда, защищённая аппликатура и обоснованное арпеджио могут ограничить альтернативы. Веса 1/5 на чёрной этого условия не задают.
4. **R23–R26/R35/R36.** Среди оставшихся путей отбрасывать необоснованные полные переносы и затем необоснованные подкладывания/перекладывания. Адаптация внутри общей области остаётся допустимой. Скольжение не обходит R22.
5. **R25/R28/R32/R33.** Сохранить естественный выход для следующей группы. Согласовывать аппликатуру повторяемых мотивов только при совместимых руках, удержаниях, артикуляции, входе и выходе. Доказанный контекст и связность исходного голоса обязательны до сравнения повторяемости.

Внутри каждого шага сравниваются полные варианты по применимому отрезку; если выход ещё влияет на другой голос, нельзя схлопывать его в «свободную руку». Применимость проверяется до выбора, а при неустановленном допуске статус unknown сохраняется. Контрпримеры [проверены отдельно](19_Completion_Case_Verification.md). [Матрица](05_Rule_Conflict_Matrix.csv) остаётся индексом зависимостей, а не доказательством совместимости. Проверка графа запрещает циклы. Подтверждение условий — по свидетелям в [реестре](09_Exception_Register.md).
