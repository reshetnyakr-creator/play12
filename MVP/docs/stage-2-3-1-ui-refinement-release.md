# Play12 Stage 2.3.1 — метроном и геометрия рабочего пространства

База Stage 2.3 и точка отката `rollback-before-stage-2-3-1` — `f26197006a704ca3b025c789524fcbad186615f9`. Релизный SHA соответствует коммиту, который содержит этот протокол.

## Tempo Navigator

Центральная кнопка переключает метроном одиночным нажатием. Два нажатия в пределах 300 мс восстанавливают авторскую карту через существующий метод `setUserBpm(null)`; состояние метронома сохраняется. Enter и пробел переключают метроном, Home возвращает авторский темп. Стрелки и перетаскивание оставлены для изменения BPM. Ручной ввод удалён из интерфейса Tempo Navigator. Round Navigator по-прежнему открывает свой диалог ввода раунда.

При выключенном метрономе кнопка нейтральная. При включённом метрономе и остановленном транспорте она постоянно салатовая, аудиособытия не планируются. Во время активного транспорта цвет меняется по уже доставленным событиям звукового планировщика. При Pause очередь ударов очищается, пользовательский выбор сохраняется. Отдельного цикла мигания нет. Исходная карта, абсолютное смещение BPM, диапазон и ключи хранения сохранены.

## Геометрия

Измерения `getBoundingClientRect()` на контрольной мелодии при 1440×900, одинаковые для RU/EN.

| Измерение | Результат |
| --- | ---: |
| Между левыми досками и нотным полем | 10 px |
| Между нотным полем и Practice Board | 10 px |
| Между Skill Bank и Practice Board по вертикали | 10 px |
| Разница ширины Profile и My Melodies | 0 px |
| Разница ширины Skill Bank и Practice | < 0,01 px |
| Разница нижних границ My Melodies, Playback, Practice | < 0,01 px |
| Разница верхних границ Profile, нотного поля и Skill Bank | ≤ 0,16 px |
| Верхняя граница нотного поля Stage 2.3 → 2.3.1 | 160,16 → 96,16 px |
| Высота нот | 32 px |

Название мелодии видно в библиотеке. В режиме редактирования переименование доступно в инструментах редактора. На узких экранах доски остаются на штатных вкладках. В короткой альбомной раскладке доступна вертикальная прокрутка рабочей панели.
