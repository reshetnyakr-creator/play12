## Музыкальная семантика и состояние

Музыкальные решения принимает прежний Controller. Новая педагогическая агрегация не назначает ноты, не проверяет высоту/ритм самостоятельно и не меняет временные окна. Одно завершённое ожидаемое исполнительское событие (включая весь аккорд, если он есть) — один успех в серии. Под включённым метрономом сохраняются действующие окна проверки. Добавлена только телеметрия уже отклонённого по времени ввода, чтобы серия могла сбрасываться; решение принять/отклонить ноту не изменено.

Серия начинается на фактическом старте текущего задания. Wrong input и timing rejection сбрасывают серию; Pause, Stop, Restart и новый музыкальный старт не переносят незавершённую серию. Проигрывание системой не даёт `source:user` и не засчитывается. Пятая принятая нота даёт ровно один OK12, затем переход к RoundBoard. Конец произведения больше не является критерием этапа метронома.

Зелёная метка — представление, а не источник подсчёта проходов. Учебное состояние хранит число полных проходов; первый сохраняется и переживает reload/паузу. Ошибка ломает только текущий незавершённый проход; первый завершённый не теряется. Пустой для выбранной руки раунд может быть пройден по существующему событию границы движка, но не окрашивается зелёным за системное проигрывание. Для текущих раундов 2–4 есть реальные исполнительские действия, что проверено сквозным проходом.

Поздняя смена нуля, Spotlight, Grab, OK12, редактор, калибровка, цветовая разметка и сохранённые произведения не заменялись.

## Геометрия

Начальные кнопки RU/EN одинаковы: на 1440/1280/1024 — **380×64 CSS px**, на 390 — **346×64**, на 375 — **331×64**; вертикальный интервал 22 px. Continue, как прежде, появляется при наличии сохраняемого состояния; для нового пользователя без сессии показывается только Start over.

Размеры Practice сравнивались с Main при одинаковой ширине музыкального блока (304.5 px с двумя боковыми музыкальными лентами) и на mobile при одинаковом диапазоне нот 47–79. Сравнение разных композиций без учёта наличия лент давало разные доступные коридоры; это зависимость от содержимого, а не изменение размера панели Spotlight.

| 1440×900 | 343.589 | 41.980 | 546.178 |

На narrow абсолютный X зависит от выбранной горизонтальной зоны. В одной активной зоне относительный X совпадает; никакая desktop навигационная прокрутка не добавлена. При знакомстве Spotlight выявляет уже рассчитанную панель, а не меняет её размер. Main до/после: геометрия сохранена; в пиксельном сравнении 1440×900 обнаружены 15 пикселей с отличием не более 3/255 в области BPM (малые растровые отличия), остальной снимок совпадает.

## Проверки

- **253 JavaScript-теста, 9 Python-тестов — pass, 0 failures/skip.**
- Синтаксически разобраны 16 renderer JS и 3 inline-скрипта.
- **4 настоящих последовательных прохода всех шести этапов:** RU/EN × 1440×900/375×667, от чистого состояния до завершения, без Skip и подстановки успеха. Ноты вводились в штатный NoteOn/Off, успех решал production Controller.
- **60 экранов:** 6 этапов × RU/EN × 5 размеров — кнопки, терминология, отсутствие кириллицы в EN, метки, rail=0, клавиатура, отсутствие document overflow.
- **270 дополнительных сценариев Spotlight** (135 на язык), по 160 target rectangles на язык, без ошибок маски/карточек.
- **50 MIDI geometry cases:** 49/61/73/76/88 × 5 viewport × RU/EN; отдельные сценарии без подключённого MIDI покрыты курсом и матрицей.
- Web MIDI mock в RU/EN: калибровка, подтверждённый диапазон, Start over без потери настроек, отключение/возврат того же инструмента, другое устройство, отказ разрешения и отсутствие устройств.
- Menu/Start/CTA: 20 стартовых случаев, 10 меню, 2 CTA; реальный импорт в библиотеку, сохранность профиля/документа/активной композиции; обычный поздний ноль; восстановление; первые восемь кадров Practice.

Браузер — настоящий Chromium headless с DOM и вводом, а не mock DOM. Матрицы восстановленных состояний отдельно от четырёх последовательных проходов. Внешние запросы заблокированы; шрифт — доступный fallback.

## Ограничения и откат

Реальная аппаратная MIDI-проверка, Safari и физические мобильные touch-устройства **не проверены**. Web MIDI и диапазоны проверены имитацией устройств. Поддерживаемый физический диапазон по-прежнему 21–108. Оценки удержания/отпускания нот и педали не расширялись: используется утверждённая семантика текущего Practice.

Откат: развернуть дерево ветки `rollback-before-tutorial-ru-en-rounds-20261116` / SHA `b235c5875fe2659470f9e0a052f2bf42dc4c4605`. Для main предпочтителен новый revert-коммит с сохранением истории и последующее штатное развёртывание. Данные не мигрируются разрушительно: новые поля Tutorial обратно совместимы; библиотека, calibration и профиль не очищаются.
